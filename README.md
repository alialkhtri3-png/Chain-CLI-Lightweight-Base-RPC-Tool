# ChainCLI – Lightweight Base RPC Tool

A lightweight CLI tool for querying Base network data directly through JSON-RPC without API keys.

## Features

- Get Base Chain ID
- Get latest block
- Get ETH balance for any address
- Direct JSON-RPC communication
- Lightweight local execution
- Tested on Termux

## Network

Base Mainnet

## Status

v0.1-prototype  
Archived / Read-Only
